# ESPrint prototype · V1.0.1

Public preview: [ESPrint V1.0.1](https://samchojine.github.io/esprint-prototype/)

ESPrint's interactive Liquid Glass UI prototype, designed for iPhone 16 Pro (402 × 874 pt). The `site/` directory is published to GitHub Pages by the included workflow whenever `main` changes.

This repository contains only browser runtime files and their local assets/dependencies. Accounts, Bluetooth connectivity, cloud storage, and hardware print submission are demonstrations. Local PDF/image processing and barcode rendering run in the browser. Third-party licenses are included under `site/vendor/` and `site/assets/` where applicable.

V1.0.1 improves mobile text contrast and glass edge/shadow definition. Shadows follow the tint of each surface, including blue, teal, lavender, success, warning and destructive controls.
